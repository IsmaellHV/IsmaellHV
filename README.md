## 🚀 About Me

I'm a software developer with **7+ years of experience**, focused on **backend development** and **AI-powered applications**. I enjoy building products that make people's work easier, from conversational assistants to the APIs and infrastructure behind them.

- 🤖 **AI & chatbots:** assistants and AI agents built with Python, OpenAI, Gemini and LangChain, including WhatsApp integrations.
- ⚙️ **Backend:** REST APIs and real-time services with Node.js, TypeScript, Express, Hono and SocketCluster.
- ☁️ **Cloud & edge:** Docker deployments on AWS and DigitalOcean, plus serverless APIs on Cloudflare Workers.
- 🖥️ **Frontend:** fast, SEO-friendly web apps with React, Astro and Tailwind CSS.
- 🌱 **Currently learning:** advanced AI agents, microservices, React Native, UI/UX design and machine learning.
